## Status values

| Status | Means |
|---|---|
| `active` | Currently building |
| `shipped` | Live and done for now |
| `paused` | Started, set down, might return |
| `archived` | Not coming back. Repo kept for reference |

## Why bother

Three reasons that show up later:

1. In six months you won't remember which of four half-finished folders was the good one.
2. When something breaks, this is the fastest path from "the site is down" to the repo and
   the deploy.
3. It's the raw material for a portfolio page.

Add the row when you create the project — `/new-project` offers to do it for you.
